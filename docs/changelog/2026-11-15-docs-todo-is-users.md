# docs/TODO.md is the user's, and the agent never edits it

`docs/TODO.md` — and any file named `TODO.md` — is the user's list: no adding, ticking,
rewording or deleting. A change that completes an item says so in the turn instead, and the
agent's own follow-ups go to `docs/CLAUDE_TODO.md`; "add X to the TODO" means that file.
