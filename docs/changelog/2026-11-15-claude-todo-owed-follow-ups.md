# docs/CLAUDE_TODO.md holds the work the project owes

Work a session finds and deliberately defers now goes to `docs/CLAUDE_TODO.md` as well as its
entry's `## Detail`: one list the agent writes and drains, each item deleted when its work lands.
It is never a work queue — an item is surfaced when the user asks for a change in that area.
The file does not exist until the first item, and absent means nothing is outstanding.

## Detail
- Why a second place: an append-only entry goes on saying "deferred" after the work is done,
  so nothing in the changelog can say what is still owed. The entry keeps the reasoning.
